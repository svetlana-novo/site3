# CodeStart — Курсы программирования

Одностраничный сайт онлайн-школы программирования: программа курса (аккордеон), модули с фильтрацией, форма регистрации с валидацией и модальным окном, переключение светлой/тёмной темы.
Демо
Сайт опубликован на Netlify: **https://neon-melomakarona-302a28.netlify.app/**

Технологии
- HTML5 (семантические теги)
- CSS3 (Flexbox, Grid, CSS-переменные, адаптивность, тёмная тема)
- Vanilla JavaScript (аккордеон, фильтры, валидация формы, модальное окно, бургер-меню, счётчики)
- Деплой: GitHub + Netlify (автодеплой из ветки `main`)

programm/

Как запустить проект локально
Вариант 1 — просто открыть файл:
```javascript
Откройте index.html в любом современном браузере.
```

Вариант 2 — через локальный сервер (рекомендуется):
```bash
# Python 3
python -m http.server 8000

# или Node.js
npx serve .
```

Затем откройте http://localhost:8000

Автодеплой на Netlify
1. Репозиторий подключён к Netlify (Build settings: публикация корня репозитория, build command пустой).
2. Каждый пуш в ветку `main` автоматически пересобирает и публикует сайт.
3. Статус деплоя можно проверить на вкладке **Deploys** в панели Netlify — должен быть «Published».

Функционал JavaScript

Аккордеон — Программа обучения, открывается один пункт за раз
Фильтрация модулей — Кнопки-чипы фильтруют карточки по направлениям
Валидация формы — Проверка имени, email, телефона (с маской +7), модуля и согласия
Модальное окно — Показывается после успешной отправки формы
Тёмная тема — Переключатель в шапке, выбор сохраняется в localStorage
Мобильное меню — Бургер-меню для экранов < 720px
Счётчики — Анимированные цифры в hero-блоке
